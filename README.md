# 课时预交追踪器

单文件 HTML 应用，用于追踪预交课时：预交若干节课后，每上完一节勾选打卡，实时查看预交 / 已用 / 剩余课时数。零依赖、无后端，手机浏览器直接打开即用。

## 功能

- **课时统计**：顶部实时显示预交课时、已用课时、剩余课时
- **预交 / 追加**：输入框默认 5 节，首次填入即预交，之后可随时累加追加
- **上课打卡**：待上课列表每节一个 checkbox，勾选即完成并从列表移除，序号自动前移
- **完成报告**：默认收起，展开后按日期分组显示完成记录（含具体时间），每条支持「撤销」以恢复误触
- **数据备份**：一键导出 JSON 备份文件；导入时自动校验并确认覆盖，可用于跨设备迁移
- **深色模式**：自动跟随系统外观

## 使用方式

1. 下载本仓库的 [pm-pre-payment.html](./pm-pre-payment.html)
2. 用任意现代浏览器打开即可（手机 / 电脑均可）

也可以在 GitHub Pages 上直接访问（若已开启）：`https://alanpu.github.io/pm-pre-payment/`

## 数据说明

- 数据保存在浏览器 `localStorage`（key: `coursePrepaidTracker`），仅存于当前设备与浏览器
- 清除浏览器数据会丢失记录，建议定期「导出备份」保存 JSON 文件
- 换设备时在新设备上「导入恢复」即可还原全部数据

## 技术说明

- 单文件实现：HTML + CSS + JavaScript 全部内联，无外部依赖、无网络请求
- 移动端优先：单列卡片布局，触控目标 ≥ 26px，防 iOS 缩放的 16px 输入字号
